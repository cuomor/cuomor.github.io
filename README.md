# Cool Program

This repository now includes a small Python script that fetches a random cat image from the internet and saves it as `cat.jpg`.

## Requirements

- Python 3 (already installed on most systems)
- An internet connection to download the cat image.

## Usage

Run the script from the repository root:

```bash
python3 cool_program.py
```

The image will be saved as `cat.jpg` in the same directory. On Linux systems, the script attempts to open the image automatically. If that doesn't work, simply open `cat.jpg` using your preferred image viewer.
